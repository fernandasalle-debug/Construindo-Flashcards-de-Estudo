HTML

O esqueleto da web

O HTML define a estrutura básica e o conteúdo semântico das páginas na internet.

Estrutura

Hierarquia da informação

Organiza o texto usando títulos (h1 a h6) para determinar a ordem de importância do conteúdo.

CSS

Hora de estilizar a página

O CSS adiciona estilo visual como fontes, bordas, sombras e espaçamentos aos elementos HTML.

CSS Flexbox

Layout flexível

Facilita o alinhamento, a centralização e a distribuição dos itens na tela de forma responsiva.

CSS Estilos

Cores e estilos no CSS

Definição de paletas visuais usando cores hexadecimais, RGB ou HSL para background e textos.

CSS Arquivos

Posicionando o CSS

O CSS pode ser inline (na tag), interno (no <style>) ou externo (em um arquivo .css separado).
